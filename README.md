# EXPERIMENT 2.2

Interactive demo / experiment playground.

## Live Demo

Open `index.html` or enable **GitHub Pages** on this repository (Settings → Pages → Source: Deploy from branch → main).

## Features

- Animated particle field background
- Glitch title effect
- Four interactive experiment panels:
  - Particle energy injection
  - Glitch protocol
  - Spectrum scan
  - Core temperature overclock
- Live console output
- Fully responsive

## Stack

- Vanilla HTML / CSS / JS
- No dependencies
